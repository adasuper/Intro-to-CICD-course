Lab 4: Build the Game with a Makefile

Split the game into logic, I/O, and an entry point, then write your own Makefile that builds it into a build/ folder.

1 · Split the game into source files

The whole point of this lab is to write the Makefile, so all the C++ is given. Split the seed game into three layers, with headers in include/ and sources in src/:

tictactoe/
├── include/
│   ├── Board.h     # pure logic: board state + rules + win detection
│   └── Game.h      # I/O: drawing the board, reading moves, the loop
├── src/
│   ├── Board.cpp
│   ├── Game.cpp
│   └── main.cpp    # entry point
└── Makefile        # you write this in Section 2

Create each file at the path shown and paste in the code below.

include/Board.h — the pure logic (no I/O, so it can be tested without a keyboard later):

// include/Board.h
#ifndef BOARD_H
#define BOARD_H
#include <array>

class Board {
public:
    Board();                                // empty board, cells labelled '1'..'9'
    bool isValidMove(int cell) const;       // cell in 1..9 and not already taken
    void applyMove(int cell, char player);  // place 'X' or 'O' at cell
    bool isFull() const;                    // all nine cells taken
    char winner() const;                    // 'X', 'O', or ' ' if none yet
    char cellMark(int cell) const;          // what to display for cell 1..9
private:
    std::array<char, 9> cells;
};
#endif

src/Board.cpp — the implementation of that logic:

// src/Board.cpp
#include "Board.h"

Board::Board() {
    cells = {'1','2','3','4','5','6','7','8','9'};
}

bool Board::isValidMove(int cell) const {
    if (cell < 1 || cell > 9) return false;
    char c = cells[cell - 1];
    return c != 'X' && c != 'O';
}

void Board::applyMove(int cell, char player) {
    cells[cell - 1] = player;
}

bool Board::isFull() const {
    for (char c : cells)
        if (c != 'X' && c != 'O') return false;
    return true;
}

char Board::winner() const {
    const int lines[8][3] = {
        {0,1,2}, {3,4,5}, {6,7,8},
        {0,3,6}, {1,4,7}, {2,5,8},
        {0,4,8}, {2,4,6}
    };
    for (auto& l : lines) {
        char a = cells[l[0]];
        if ((a == 'X' || a == 'O') && a == cells[l[1]] && a == cells[l[2]])
            return a;
    }
    return ' ';
}

char Board::cellMark(int cell) const {
    return cells[cell - 1];
}

include/Game.h — the I/O layer, which owns a Board:

// include/Game.h
#ifndef GAME_H
#define GAME_H
#include "Board.h"

class Game {
public:
    void run();          // play one game to the end
private:
    void draw() const;   // print the board
    Board board;
    char player = 'X';
};
#endif

src/Game.cpp — drawing the board and the game loop:

// src/Game.cpp
#include "Game.h"
#include <iostream>

void Game::draw() const {
    for (int r = 0; r < 3; ++r) {
        std::cout << ' ' << board.cellMark(r * 3 + 1)
                  << '|' << board.cellMark(r * 3 + 2)
                  << '|' << board.cellMark(r * 3 + 3) << '\n';
    }
}

void Game::run() {
    while (true) {
        draw();
        std::cout << "Player " << player << ", cell 1-9: ";
        int cell;
        std::cin >> cell;
        if (!board.isValidMove(cell)) {
            std::cout << "invalid\n";
            continue;
        }
        board.applyMove(cell, player);
        if (board.winner() != ' ') {
            draw();
            std::cout << "Player " << player << " wins!\n";
            return;
        }
        if (board.isFull()) {
            draw();
            std::cout << "Draw\n";
            return;
        }
        player = (player == 'X') ? 'O' : 'X';
    }
}

src/main.cpp — the entry point, just three lines:

// src/main.cpp
#include "Game.h"

int main() {
    Game game;
    game.run();
}

2 · Write your own Makefile

Now write the Makefile yourself, in the project root, modelled on the lecture (Class 9, Sections 9–10). Do not copy a finished file: build it from the requirements below. Remember that every recipe line must start with a real Tab.

Your Makefile must
  1. Define variables: CXX = g++, CXXFLAGS = -std=c++17 -Wall -Iinclude, and BUILD = build.
  2. Detect the shell with the uname check from the lecture, setting EXE (the program: build/tictactoe, or build/tictactoe.exe on Windows), MKDIR, RMDIR, and RUN.
  3. Have a default target that links the three object files (build/Board.o build/Game.o build/main.o) into $(EXE).
  4. Have a pattern rule that compiles each src/%.cpp into build/%.o, listing the headers in include/ as prerequisites so editing a header triggers a rebuild.
  5. Have a rule that creates the build/ folder before anything is compiled into it.
  6. Declare .PHONY targets run (build, then run $(EXE)) and clean (delete the build/ folder).

The only differences from the lecture's hello Makefile are the names: the program is tictactoe, and there are three source files instead of two.

3 · Test your Makefile

From the project root, run these three commands and check each behaves as described:

make           # compiles src/*.cpp into build/*.o, links build/tictactoe
make run       # builds if needed, then starts the game
make clean     # deletes the whole build/ folder
  • make creates the build/ folder and the executable inside it. Run make a second time: it should report everything is up to date and compile nothing.
  • make run launches the game. Play through a win (e.g. X on cells 1, 2, 3) and a draw to confirm the logic works.
  • make clean removes build/ entirely, so git status shows only your source files and the Makefile.
