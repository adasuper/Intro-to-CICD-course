Introduction to CI/CD

A short summer course

A hands-on, four-day introduction to version control, build systems, and continuous integration & delivery: taught entirely around one small C++ project: a console Tic-Tac-Toe game that grows, lab by lab, into an automatically built and tested pipeline on Gitee.

Prereq: basic C++ Tools: Git · Gitee · Make · Gitee Go

Project Brief

The course project thread: a single Tic-Tac-Toe codebase carried across every module: versioned in Lab 1, kept clean and conflict-free in Lab 2, branched in Lab 3, built with Make in Lab 4, and put behind an automated build-and-test pipeline in Lab 5, before teams extend it in the final project.
